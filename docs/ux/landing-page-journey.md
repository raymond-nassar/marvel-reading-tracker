# User Journey: First Reading Order

## Persona
- **Who**: New user, just installed, empty library
- **Goal**: Start reading Marvel comics in a sensible order
- **Context**: Evening, at a desktop, Marvel Unlimited tab already open
- **Success Metric**: Has a reading order in their library and knows the next issue

## Stage 1 — Arrival
**Doing**: Launches the app, lands on the dashboard
**Thinking**: "Okay, what does this thing actually give me?"
**Feeling**: 🤔 Curious, evaluating
**Pain points**:
- Largest element on screen is an empty dashed box
- No evidence any reading orders exist
**Opportunity**: Show the catalog itself as the hero. Content *is* the CTA.

## Stage 2 — Orientation
**Doing**: Reading the sidebar, weighing "Browse the catalog" vs "New empty list"
**Thinking**: "Do I want a curated list or do I build my own? I don't know yet."
**Feeling**: 😕 Mild decision paralysis
**Pain points**:
- Options presented as equals; no recommended path
- "New empty list" is a power-user action shown to a first-run user
**Opportunity**: Make curated browsing the default. Demote empty-list creation to
a quiet secondary row.

## Stage 3 — Evaluation
**Doing**: Comparing reading orders
**Thinking**: "How long is this? Where does it start? Is it beginner-friendly?"
**Feeling**: 😐 Cautious — worried about committing to 200 issues
**Pain points**:
- Cannot assess scope without opening each order
- No sense of difficulty or entry point
**Opportunity**: Surface issue count and length on the card. Add filter chips
including "Short (< 20 issues)" and "Beginner-friendly".

## Stage 4 — Commitment
**Doing**: Adding a reading order to their library
**Thinking**: "Did that work? Where did it go?"
**Feeling**: 😬 Uncertain until confirmed
**Pain points**:
- Risk of silent success with no feedback
**Opportunity**: Button flips in place to "✓ In library → Open". Announce via
live region. New list appears under READING ORDERS in the sidebar.

## Stage 5 — Return
**Doing**: Reopening the app days later
**Thinking**: "Which issue was I on?"
**Feeling**: 😊 Confident if answered immediately, annoyed if made to hunt
**Pain points**:
- Current design shows the same empty-state hero regardless of library contents
**Opportunity**: Hero becomes "Continue reading" — last-read list, progress bar,
next issue, direct Unlimited link. Catalog demotes to "Discover more".

## Emotional Arc
Curious → Paralyzed → Cautious → Uncertain → Confident
**Target arc**: Curious → Interested → Confident → Reading
