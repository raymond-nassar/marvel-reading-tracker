        Backup & settings

        Everything lives in this browser, at this exact address. Nothing is uploaded.

        Backup and restore

        Export regularly — clearing site data for this address erases your progress.

        Restore from a backup

        A snapshot of your current data is kept, so a restore can be undone once.

        Cover art

        Covers are loaded straight from Marvel's own servers using the address the metadata API reports. This app stores only that address — never the image itself — and never proxies or re-hosts artwork. Switch covers off and every cover becomes a plain typographic tile.

        Metadata source

        The default is the community API this was built against. If it disappears it is MIT-licensed and self-hostable — point this at your own copy.
