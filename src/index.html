        About this app

        What this is, where the data comes from, and what it does not do.

        An unofficial fan project

        This is an unofficial fan project. It is not made by, endorsed by, or affiliated with Marvel or The Walt Disney Company. Marvel, Marvel Unlimited, and all related names, characters, and logos are trademarks of Marvel Characters, Inc.

        Metadata and links only

        No comic content is stored, copied, proxied, or served. The app tracks which issues you have read and links out to Marvel's own site and reader. Reading an issue requires your own Marvel Unlimited subscription. Cover images load directly from Marvel's own servers and can be switched off.

        Where the metadata comes from

        Issue, series, and creator metadata comes from the community marvel.emreparker.com API, built from emreparker/marvel-comics (MIT). The snapshot ends in 2025, so very recent issues may be missing. You can still add those by hand. The API base URL is configurable under Backup & settings.

        Curated reading orders

        Bundled reading orders are imported from community sources, not authored here. Each list in the catalog shows its source and the date it was last updated.

        Your data

        Everything lives in this browser, at this exact address. Nothing is uploaded, there is no account, and no server sees your reading progress. Clearing site data for this address erases it, so export a backup regularly.

        This build

        Version unknown, data format unknown. A change to the data format means an older build cannot read data saved by this one, so export a backup before upgrading across one.
