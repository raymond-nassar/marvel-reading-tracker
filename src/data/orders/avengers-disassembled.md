# Avengers Disassembled: Issue-by-Issue Reading Checklist

Compiled by hand for this project from a reader's outline of Comic Book Herald's guide to Avengers
trade collections, covering the 2004 Avengers Disassembled story, read as a reference and
re-expressed here. It is not derived from Marvel metadata and cannot be
checked against it; only the issue ids and titles come from Marvel, by resolving each issue the
outline names.

This is the shortest order here on purpose. It is the four-issue Brian Michael Bendis story that
ends the Busiek, Perez and Johns era of Avengers (1998), plus the one-shot that closes it out.
Marvel indexes that one-shot as Avengers Finale (2004), not Avengers: Finale.

The outline's notes name New Avengers (2004) #1-6 as what this leads into. That is context rather
than part of the story, so it is not shipped here; the Civil War order in this catalog picks up
that series.

Because the selection cannot be verified against Marvel, the order says so on its catalog card
rather than presenting it as Marvel's own. See
[the data provenance record](../../../docs/DATA_PROVENANCE.md) for what that means for reuse.
