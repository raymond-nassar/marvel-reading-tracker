# Marvel Fresh Start Avengers: Issue-by-Issue Reading Checklist

Compiled by hand for this project from a reader's outline of Comic Book Herald's guide to Avengers
trade collections, covering the Jason Aaron Fresh Start era, read as a reference and re-expressed
here. It is not derived from Marvel metadata and cannot be
checked against it; only the issue ids and titles come from Marvel, by resolving each issue the
outline names. The sections are the trades the outline lists, kept in its order, including the ones
it groups under a later Latest Additions heading.

The Wakanda Forever row names four books and no issue numbers, and all four are single issues:
Amazing Spider-Man: Wakanda Forever, X-Men: Wakanda Forever, Avengers: Wakanda Forever and Black
Panther Annual (2018). They are shipped in the outline's order, which is also the order they were
published in.

Two rows ask for Free Comic Book Day material, in the first Jason Aaron volume and the first Savage
Avengers volume. Marvel indexes those giveaways outside the series they support, so they are named
here rather than shipped.

One row cannot be shipped, and is named rather than dropped silently. Savage Avengers Vol. 3, Enter
the Dragon, is listed with no issue numbers at all, and which issues a trade collects is not
something Marvel's issue metadata records. Guessing the range from where Vol. 2 ends would be an
invention, so the section is gone. The issues it would hold continue from Savage Avengers (2019)
#11.

The gap at Avengers #18-20 is the outline's: it goes from the third Jason Aaron volume straight to
the fourth at #21-25.

Marvel's metadata holds two separate records for Savage Avengers #1, alike but for their ids. A list
holds an issue once, so the lower id is the one here.

Because the selection cannot be verified against Marvel, the order says so on its catalog card
rather than presenting it as Marvel's own. See
[the data provenance record](../../../docs/DATA_PROVENANCE.md) for what that means for reuse.
