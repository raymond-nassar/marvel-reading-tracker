# The Best of Captain America: Issue-by-Issue Reading Checklist

Compiled by hand for this project from a reader's outline of Comic Book Herald's guide to the
best Captain America comics on Marvel Unlimited, read as a reference and re-expressed here. It is
not derived from Marvel metadata and cannot be checked against it; only the issue ids and titles
come from Marvel, by resolving each issue the outline names. The division into sections is the
outline's, and the sections are kept in the order it gives them rather than re-sorted into
publication order, so the modern Brubaker run comes before the Silver and Bronze Age material.

Five departures from the outline, all deliberate. The outline opens with Captain America: The
Winter Soldier at Captain America (2004) #1-14, which is wholly contained in the Brubaker run it
lists next at #1-50; a list holds an issue once, so the two are shipped as the single #1-50
section. The outline names the renumbered issues as Captain America (2009) #600-619, and Marvel's
metadata has no such series: those issues are Captain America (2004) continuing under restored
numbering, and they carry that title here. Captain America #615.1 is included, because it falls
inside the range the outline names and was published between #615 and #616. Reborn resolves to
the 2009 six-issue mini-series; Marvel's other Reborn record is a trade collection rather than an
issue, so it is not here. Rebirth resolves to a single issue, Captain America: Rebirth (2010) #1,
which shipped in 2011 after the mini-series it recaps.

Because the selection cannot be verified against Marvel, the order says so on its catalog card
rather than presenting it as Marvel's own. See
[the data provenance record](../../../docs/DATA_PROVENANCE.md) for what that means for reuse.
